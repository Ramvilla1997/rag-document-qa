Incident Runbook: Elevated Error Rates. Page the on-call engineer if the 5xx error rate exceeds 2 percent for more than 5 minutes. First, check the deployment dashboard for a release in the last hour and roll it back if the errors began after the release. Second, check database connection pool saturation; if the pool is at its limit, restart the affected API pods one at a time to clear stuck connections. Third, check upstream dependency status pages. Post an update in the incident channel every 15 minutes until the error rate returns below 0.5 percent. Write a blameless postmortem within five business days of resolution.
