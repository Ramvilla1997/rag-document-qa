Public API Guide. All requests must include a bearer token in the Authorization header. Tokens are issued from the developer portal and expire after 90 days. Rate limits are 600 requests per minute per token. When you exceed the limit the API returns HTTP 429 with a Retry-After header in seconds. Pagination uses cursor parameters: pass the nextCursor value from the previous response as the cursor query parameter. Page size defaults to 50 and cannot exceed 200. Webhooks are delivered with an HMAC-SHA256 signature in the X-Signature header, computed over the raw request body with your webhook secret. Reject any webhook whose signature does not match.
